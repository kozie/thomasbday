# Full-screen birthday scratch card

A zero-dependency static site designed for GitHub Pages. The whole phone screen is the scratch surface.

## Prize artwork

The current prize artwork is `prize-thomas.jpg`. It uses a 9:16 portrait ratio so it fills a typical phone screen without awkward cropping. To replace it later, keep the same filename or update the `src` on the `.prize__image` element in `index.html`.

## Publish with GitHub Pages

1. Push these files to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose your main branch and the `/ (root)` folder, then save.

No npm install or build command is needed.
